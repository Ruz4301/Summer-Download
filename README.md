# Summer for Windows

Summer is a voice assistant for Windows 10 and 11 (64-bit).

## Download

**[⬇ Download Summer-Setup-1.0.0.exe](https://github.com/Ruz4301/Summer-Download/releases/latest/download/Summer-Setup-1.0.0.exe)** (about 230 MB)

1. Run the installer. It installs for your user only, with no administrator prompt.
2. If Windows SmartScreen says it protected your PC, choose **More info → Run anyway**. The installer is not code-signed.
3. Open Summer from the Start menu. The first launch asks for a Gemini API key (free from Google AI Studio), your name and job, your colours, and your microphone and speakers.
